# SELECT truth FROM lies;

**SQLで謎を解く脱出ゲーム**

205号室の住人が、3週間前から姿を消している。
管理会社の新人システム担当として、マンションの管理システムに残った記録をSQLで調べ、嘘の中から真実を取り出してください。

- ブラウザだけで遊べます（インストール不要）
- SQLを知らなくても大丈夫です。前任者の手書きノートがゲーム内にあります
- 進み具合はブラウザに自動で保存されます

## 遊び方

### 基本の流れ

1. **部屋を調べる**：気になるところをクリックすると、主人公が調べます。手に入れた物は左上の「持ち物」から見返せます。
2. **パソコンを使う**：管理人室のパソコンで、依頼人の桐山さんからのメールを読みます。
3. **SQLで調べる**：デスクトップの「ターミナル」に SQL を打って、マンションの管理システムの記録を調べます。
4. **メールで報告する**：分かったことは、メールの返信欄から桐山さんに報告します。記録を書き換えて解決する場面もあります。

次にやることは、画面の左下に出ています。クリックすると畳めます。

### 画面のボタン

| ボタン | できること |
|---|---|
| 持ち物（左上） | 手に入れた手帳やノートなどを読む |
| ログ（左上） | これまでのセリフを読み返す |
| メニュー（右上） | セーブ、設定（文字の大きさ・速さ・音量）、タイトルに戻る |
| 移動（部屋の画面の右上） | 別の場所へ移動する |
| 周りを調べる（パソコンの画面の左上） | パソコンから離れて、部屋に戻る |

会話は、クリック / Enter / Space で進みます。調べている途中で出る主人公の「気づき」は、クリックか Space（入力欄が空のとき）/ Esc で閉じます。

### ターミナルの使い方

- SQL の文は、最後に `;` を付けてから Enter で実行します。`;` を忘れると `...>` が出て続きを待つので、`;` だけ打って Enter してください。
- Shift+Enter で改行、↑ / ↓ で前に打った文を呼び出せます。
- 点（.）で始まる命令も使えます。

| 命令 | できること |
|---|---|
| `.tables` | テーブルの一覧を出す |
| `.schema テーブル名` | テーブルの列と、その種類（TEXT＝文字、INTEGER＝整数）を見る |
| `.help` | 使える命令の一覧を出す |
| `.clear` | 画面を消す |

- 結果は先頭200行まで表示されます。それより多いときは、`WHERE` で絞ったり、`ORDER BY` と `LIMIT` で見る行を選んだりしてください。
- 書き換えて失敗したときは、ターミナルの右上の「章の最初に戻す」で、その章を始めたときのデータベースに戻せます。`BEGIN;` してから書き換えれば、`ROLLBACK;` で取り消すこともできます。
- テーブルを消すなど、物語を壊す操作は `not authorized` で止まります。

### SQLが分からないとき

- 管理人室の本棚に、前任者の日向さんが残した**SQLのノート**があります。「はじめに」から順に読めば、このゲームで使う書き方はひととおり分かります。
- 結果の表の列名にマウスを乗せると、その列の意味が出ます。

### 困ったときのヒント

ターミナルで次のように打つと、今調べていることのヒントが出ます。

```sql
SELECT * FROM hint;
```

実行するたびに、ヒントが1段階ずつ詳しくなります（3段階目は、ほぼ答えです）。メールの「桐山に相談」からも、同じヒントを聞けます。

### セーブ

進み具合は、ブラウザに自動で保存されます。タイトル画面の「つづきから」で続きを遊べます。同じブラウザでも、プライベートウィンドウやサイトデータの削除で消えることがあります。

## ローカルで遊ぶ

`file://` で直接開くと読み込みに失敗するので、簡単なWebサーバー越しに開いてください。

```sh
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```
